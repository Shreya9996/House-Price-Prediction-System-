# House Price Prediction System

This project is a Machine Learning based House Price Prediction web application built using Flask.

## Features
- Predicts house price based on user inputs
- Uses Linear Regression with MinMaxScaler
- Web interface using HTML & CSS

## Tech Stack
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy

## How to Run
```bash
pip install -r requirements.txt
python app.py
